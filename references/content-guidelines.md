# Content Guidelines：反 slop、内容、投屏字号

这份清单管「不做什么」。AI 的默认视觉是 slop，不主动避开就会出现。

这里的目标是**论述被看清**，不是品牌被认出。

## 黑名单

**❌ 激进渐变 / mesh / rainbow 铺底**  
渐变只允许极淡、单色系、当纸纹。想加渐变 → 大概率不加。

**❌ 圆角卡片 + 左彩色 border**  
这是 Dashboard 味。强调用字重、字号、留白、一条细线。

**❌ Emoji 当图标**  
标题前的装饰符号、列表前的彩色勾，一律不用。箭头用 `→` `—` `·`，不要 emoji。

**❌ SVG 画人、场景、设备、物品**  
灰块 +「示意图位」比拙劣插画强。SVG 只用于：小 icon、几何装饰、数据图、论述结构图解。

**❌ 每条标题都配 icon**  
装饰 icon 是噪音。差异化信息（稿里的对比、数字、步骤）用排版表达，不靠 icon 凑密度。

**❌ Data slop / Quote slop**  
不要编「99.9%」「10,000+ 用户」、不要编名人名言。稿里没有的数字和引用，不上屏。

**❌ Inter / Roboto / Arial / 纯系统字体做 Display**  
标题用 Newsreader + Noto Serif SC（见 SKILL 默认语法）。正文可以用系统无衬线。不要用 Space Grotesk、Fraunces 赶时髦。

**❌ 凭空另起一套色**  
没有品牌色。用暖底 `#FAF7F2` + 墨 `#1C1917` + accent `#C04A1A`。缺的深浅用同色相 `oklch` 插值。

**❌ Bento 为了 bento**  
信息结构适合网格再用。陈述页更常是大字 + 一条支撑。

## 内容准则

每个元素都要 earn its place。去掉它主张仍成立 → 去掉。空白用构图解决，不靠填内容。

不要单方面加一页「会更好看」的章节。稿里没有的论点，先问。

中文用「」不用 ""。

## 投屏字号（1920×1080）

- 正文 ≥ 24px，理想 28–36px
- 标题 60–120px
- 金句 / 封面 160–220px
- 对比度：正文 vs 底至少 4.5:1

## 排版可用

```css
h1, h2 { text-wrap: balance; }
p { text-wrap: pretty; }
```

犹豫时：渐变、emoji、左 border 卡片、SVG 插画、装饰 quote、Inter、紫配色 → 不加。
